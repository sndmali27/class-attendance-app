# Class 6 Marathi Result App

Android Studio project for the offline Class 6 school result app.

## Build APK

The GitHub Actions workflow `.github/workflows/build-result-apk.yml` builds a debug APK. Open the repository's Actions tab, select **Build Class 6 Result APK**, and download the `class6-result-debug-apk` artifact from a successful run.

## Build locally

Open this folder in Android Studio and run the `assembleDebug` Gradle task.

The app stores data locally on the device. Export a backup regularly. Confirm the school's official grading rules before using results for official reporting.
